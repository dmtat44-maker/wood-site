# ЛесМаркет — сайт для заказа изделий из дерева

Готовый адаптивный сайт для продажи и заказа пиломатериалов: доски, бруски, лаги, брус и другие изделия из дерева.

## Что внутри

- `index.html` — главная страница сайта.
- `style.css` — стили, адаптивность, анимации.
- `script.js` — меню, слайдер, модальные окна, валидация форм.
- `README.md` — инструкция по запуску.

## Функции

- Адаптивный mobile-first дизайн.
- Bootstrap 5 CSS через CDN.
- Google Fonts через CDN.
- Vanilla JS без фреймворков.
- Главная, каталог, о нас, контакты.
- Рекламный блок.
- Слайдер.
- Модальные окна.
- Форма заявки с валидацией.
- SEO meta-теги.
- Alt-тексты для изображений.
- Быстрая загрузка: SVG-изображения без тяжёлых файлов.

## Как запустить

1. Скачайте файлы проекта.
2. Положите рядом:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы проекта в корень репозитория.
3. Откройте настройки репозитория.
4. Перейдите в раздел `Pages`.
5. В `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Сохраните настройки.
7. Через некоторое время GitHub выдаст ссылку на сайт.
